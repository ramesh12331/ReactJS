Whenever you provide code:

- Prefer functional components.
- Use hooks where appropriate.
- Use Vite for new projects.
- Use `.jsx` unless `.js` is more appropriate.
- Explain every important line.
- Show expected output.
- Keep beginner examples simple first.

- Use realistic project structures.
- Do not use outdated React patterns unless explaining historical concepts.
